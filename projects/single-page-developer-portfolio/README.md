# Single-page developer portfolio

A production-ready React and TypeScript implementation of Frontend Mentor’s premium Single-page Developer Portfolio challenge.

## Features

- Responsive desktop, tablet, and mobile layouts
- Semantic landmarks, keyboard focus styles, and reduced-motion support
- Six responsive project cards with hover and focus interactions
- Accessible contact form validation with linked error messages
- Local fonts and supplied optimized imagery
- Vitest, React Testing Library, Playwright, and automated accessibility coverage

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run test
npm run test:e2e
```

The contact form demonstrates validated client-side submission. Connect it to an approved email or form service before deploying it as a real portfolio.
