# Creative agency single-page site

A responsive, accessible React and TypeScript implementation of the Frontend Mentor Creative agency premium challenge.

## Features

- Responsive desktop, tablet, and mobile layouts with supplied art-directed imagery
- Mouse and keyboard-operable project carousel with announced slide content
- Accessible mobile menu with focus trapping, Escape handling, and focus restoration
- Strong focus states and reduced-motion support
- Unit, browser, responsive-overflow, and automated accessibility tests

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
npm run test
npm run test:e2e
```
