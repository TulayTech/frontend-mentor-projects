# Healthy Recipe Finder

A responsive React and TypeScript implementation of Frontend Mentor’s premium Recipe Finder challenge.

## Highlights

- Home, About, recipe index, and recipe detail routes
- Instant name and ingredient search
- Composable prep- and cook-time filtering
- Responsive recipe imagery and related-recipe cards
- Accessible mobile navigation, focus styles, and result announcements
- Vitest, React Testing Library, Playwright, and automated accessibility coverage

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run test
npm run test:e2e
```
