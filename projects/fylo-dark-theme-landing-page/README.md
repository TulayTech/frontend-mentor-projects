# Fylo dark theme landing page

A responsive, accessible React and TypeScript implementation of the Frontend Mentor Fylo dark theme landing page challenge.

## Features

- Responsive hero, feature grid, productive section, testimonials, signup card, and footer
- Challenge-matched hover and validation states
- Accessible landmarks, skip link, form feedback, focus styles, and reduced-motion support
- Unit, browser, responsive-overflow, and automated accessibility tests
- Honest local demo behavior; email addresses are not transmitted or stored

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
npm run test
npm run test:e2e
```
