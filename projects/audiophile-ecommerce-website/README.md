# Audiophile e-commerce website

A responsive React and TypeScript implementation of Frontend Mentor’s Audiophile premium e-commerce challenge.

## Features

- Home, category, and data-driven product detail pages
- Persistent cart with editable quantities and live totals
- Accessible checkout validation with e-Money and cash-on-delivery options
- Shipping, VAT, and grand-total calculations
- Order confirmation dialog and completed-order cart reset
- Responsive navigation, local assets, keyboard focus states, and reduced-motion support
- Unit, integration, accessibility, and end-to-end browser tests

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
npm run test
npm run test:e2e
```
