# Space Tourism website

A responsive React and TypeScript implementation of Frontend Mentor’s Space Tourism challenge.

## Highlights

- Stable routes for every destination, crew member, and technology item
- Responsive desktop, tablet, and mobile artwork
- Keyboard-accessible navigation with a focus-trapped mobile drawer
- Semantic selectors, visible focus styles, and reduced-motion support
- Vitest, React Testing Library, Playwright, and automated accessibility checks

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run test
npm run test:e2e
```
