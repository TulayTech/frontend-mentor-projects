# Loopstudios landing page

A responsive, accessible React and TypeScript implementation of the Frontend Mentor Loopstudios landing page challenge.

## Features

- Responsive hero, company story, creation gallery, and footer based on the supplied designs
- Art-directed desktop and mobile imagery
- Keyboard-accessible mobile navigation with focus trapping, Escape handling, and focus restoration
- Challenge-matched hover and focus states
- Unit, browser, responsive-overflow, and automated accessibility tests

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
npm run test
npm run test:e2e
```
