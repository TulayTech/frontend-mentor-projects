# Pod request access landing page

A responsive, accessible React and TypeScript implementation of the Frontend Mentor Pod request access challenge.

## Features

- Responsive desktop, tablet, and mobile layouts based on the supplied design reference
- Accessible email form with the challenge’s empty and invalid-email states
- Honest local demo confirmation; no email is transmitted or stored
- Keyboard focus styles and reduced-motion support
- Unit, browser, responsive-overflow, and automated accessibility tests

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
npm run test
npm run test:e2e
```
