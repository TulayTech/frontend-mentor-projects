# Coffeeroasters subscription site

A responsive React and TypeScript implementation of Frontend Mentor’s premium Coffeeroasters challenge.

## Highlights

- Home, About, and Create Plan routes
- Interactive five-step subscription builder
- Conditional grind controls for capsule orders
- Weight-based shipment pricing and monthly totals
- Accessible order-summary modal with focus management
- Responsive navigation, local imagery, reduced-motion support, and automated accessibility checks

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run test
npm run test:e2e
```
