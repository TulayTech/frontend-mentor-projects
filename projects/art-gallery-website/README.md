# Modern Art Gallery website

A responsive, accessible two-page React and TypeScript implementation of the Frontend Mentor Art Gallery premium challenge.

## Features

- Gallery and location routes with client-side navigation
- Responsive art-directed 1x and 2x imagery
- Supplied static map and location details without third-party tracking or map dependencies
- Challenge-matched hover/focus button treatment
- Unit, routing, browser, responsive-overflow, and automated accessibility tests

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
npm run test
npm run test:e2e
```
