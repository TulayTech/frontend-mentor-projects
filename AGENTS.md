# Frontend Mentor Agent Instructions

## Purpose

Complete one Frontend Mentor project at a time as a learning and portfolio exercise. Preserve honest attribution and keep this work separate from TuTech client projects.

## Required workflow

- Read the selected challenge’s README, brief, design guidance, and local agent instructions before editing.
- Use AI to explain decisions and support the owner’s learning. The owner should be able to understand and discuss the finished implementation.
- Work on a challenge-specific feature branch. Never implement directly on the protected default branch.
- Do not change unrelated projects.
- Prefer semantic, accessible, mobile-first implementation and reduced-motion support.
- Use strong typing and existing dependencies where available.
- Do not add a major dependency without approval.
- Do not commit `.env` files, credentials, design-source files, starter archives, dependencies, or build output.

## Validation

Run the project’s build, lint, and test scripts before reporting completion. Run browser or Playwright checks for responsive layouts and interactive journeys. Do not report completion when a required check fails.

## Completion report

Report what changed, files changed, commands run, results, remaining risks, lessons learned, and the recommended next task. Do not merge or deploy without approval.
