# TuTech Frontend Mentor Projects

This repository is reserved for Frontend Mentor challenges completed one project at a time with the TuTech Codex agent.

## Working model

1. Choose one challenge and copy its downloaded starter files into `projects/<challenge-slug>/`.
2. Read the challenge brief and its `AGENTS.md` before planning.
3. Complete one approved milestone on a feature branch.
4. Run the project’s build, lint, tests, and relevant browser checks.
5. Submit the live URL and repository to Frontend Mentor.
6. Add the reviewed project to the separate Frontend Mentor section on the TuTech website.

## Portfolio attribution

Use this note in each project README and TuTech case study:

> Design provided by Frontend Mentor. Built by TuTech with Codex-assisted planning, implementation, testing, and review.

Do not present these projects as paid client work or as original TuTech visual designs. Do not redistribute premium design files, Figma files, or raw starter packages.
